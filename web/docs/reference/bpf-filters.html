BPF filter reference

Use Berkeley Packet Filter (BPF) expressions to narrow packet capture scope.

Common examples

  • tcp port 22 — Capture SSH traffic.
  • host 192.168.1.1 — Capture traffic to a specific host.
  • udp port 53 — Capture DNS queries.
  • net 10.0.0.0/24 — Capture traffic for a subnet.

Tips

Start with a narrow filter to keep captures small, then widen as needed.
