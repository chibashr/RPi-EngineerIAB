FAQ

Common questions about RPi Engineer-in-a-Box.

Does it work offline?

Yes. The web interface is served locally from the device.

Where are capture files stored?

Capture files are stored on the device and can be downloaded from the Packet capture page.

Do I need authentication?

No. The default workflow assumes a trusted WiFi hotspot for field use.
