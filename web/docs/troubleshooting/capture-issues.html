Capture issues

Troubleshoot packet capture failures and performance concerns.

Capture fails to start

Symptom: Capture does not start or ends immediately.

Common causes: Interface not available or missing permissions.

Resolution: Select another interface and retry.

Capture file too large

Symptom: Capture fills storage quickly.

Common causes: High traffic or no filter.

Resolution: Add a BPF filter or shorten the duration.

Live view not updating

Symptom: Live view shows no packets.

Common causes: Filter too restrictive or no traffic.

Resolution: Clear filters and generate test traffic.
