Serial issues

Resolve device detection and Serial console session problems.

Device not detected

Symptom: No devices listed in Advanced → Serial console.

Common causes: Adapter not connected or unsupported chipset.

Resolution: Reconnect the adapter and refresh the page.

Permission denied

Symptom: Cannot open device or session fails to start.

Common causes: Serial device permissions missing.

Resolution: Reboot or re-run the installer to apply permissions.

Garbled output

Symptom: Output is unreadable.

Common causes: Incorrect baud rate or parity.

Resolution: Update device settings to match the target device.

WebSocket "Invalid frame header" or connection fails

Symptom: Serial console shows disconnected and the browser console reports WebSocket connection failed: Invalid frame header.

Common causes: The API server needs gevent for reliable WebSocket support; nginx proxy may be misconfigured.

Resolution:

  1. Ensure gevent is installed: pip install gevent (or re-run the installer).
  2. Set RPI_ENGINEER_USE_GEVENT=1 in the API service environment (the installer does this by default).
  3. Restart the API: sudo systemctl restart rpi-engineer-api.
  4. If behind nginx, ensure /ws/ has proxy_http_version 1.1, Upgrade, and Connection "upgrade" headers. Run sudo /opt/rpi-engineer/bin/apply-web-permissions.sh to re-apply the nginx config.
