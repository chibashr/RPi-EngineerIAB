Common issues

Start here when the web interface is slow or the device behaves unexpectedly.

Web interface not loading

Symptom: Browser cannot reach http://192.168.50.1.

Common causes: Not connected to WiFi hotspot, device still booting.

Resolution: Reconnect to the hotspot and wait two minutes for full boot.

403 Forbidden when opening 192.168.50.1

Symptom: Browser shows 403 Forbidden when opening http://192.168.50.1 (e.g. from hotspot or LAN).

Common causes: (1) Nginx access rules blocking LAN/hotspot. (2) Web root not readable by nginx—nginx runs as www-data (or the user in /etc/nginx/nginx.conf); if it does not own or cannot read the web root, you get 403.

Resolution: Run the bundled fix once (as root): sudo /opt/rpi-engineer/bin/apply-web-permissions.sh. It rewrites the nginx config and sets web root ownership so the UI is reachable. After that, applying an update from the web UI will re-run this script automatically if you have run the full installer at least once (it adds a sudoers rule). Alternatively, re-run the full installer: sudo /opt/rpi-engineer/bin/install.sh. To confirm the cause, check /var/log/nginx/error.log (e.g. Permission denied or 13 means file permissions).

No network access

Symptom: WAN shows disconnected on the dashboard.

Common causes: Ethernet unplugged or USB modem not detected.

Resolution: Reseat cables, confirm link lights, and retry.

High temperature warning

Symptom: Temperature alert or degraded status.

Common causes: Poor ventilation or high workload.

Resolution: Improve airflow and pause heavy captures.
