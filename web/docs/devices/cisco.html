Cisco device connection guide

Default serial settings and steps for Cisco routers and switches.

Default settings

  • Baud rate: 9600
  • Data bits: 8
  • Parity: none
  • Stop bits: 1
  • Flow control: none

Connection steps

  1. Connect the console cable to the Cisco device.
  2. Open Advanced → Serial console.
  3. Select the device and confirm settings.
  4. Click Open console.

Troubleshooting

If output is garbled, confirm the baud rate matches the device.
