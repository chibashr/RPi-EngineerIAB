HP/Aruba device connection guide

Default serial settings and steps for HP/Aruba switches.

Default settings

  • Baud rate: 115200 (newer devices) or 9600 (older devices)
  • Data bits: 8
  • Parity: none
  • Stop bits: 1
  • Flow control: none

Connection steps

  1. Connect the console cable to the HP/Aruba device.
  2. Open Advanced → Serial console.
  3. Select the device and confirm settings.
  4. Click Open console.

Troubleshooting

If output is garbled, switch between 9600 and 115200 baud.
