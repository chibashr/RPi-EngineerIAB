First serial session

Connect a USB-to-serial adapter and open a Serial console session in Advanced mode.

Before you start

  • You are connected to the WiFi hotspot.
  • A supported USB-to-serial adapter is available.
  • Advanced mode is enabled.

Start a session

  1. Connect the USB-to-serial adapter to the device.
  2. Open Advanced → Serial console.
  3. Select the device and confirm the baud rate.
  4. Click Open console to start the session.

Save logs

  1. Keep the session open while you gather output.
  2. Use the log controls to download the session log.
