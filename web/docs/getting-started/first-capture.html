First packet capture

Start a packet capture in Advanced mode and download the PCAP for analysis.

Before you start

  • You are connected to the WiFi hotspot.
  • Advanced mode is enabled.
  • You know which interface carries the target traffic.

Start the capture

  1. Open Advanced → Packet capture.
  2. Select the interface (for example, eth0 or usb0).
  3. Optional: enter a filter to reduce traffic noise.
  4. Click Start capture.

Stop and download

  1. Click Stop capture when you have enough data.
  2. Select the capture from the list.
  3. Click Download to save the file.
