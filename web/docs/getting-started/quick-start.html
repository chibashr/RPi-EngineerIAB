Quick start

Connect to the WiFi hotspot, open the web interface, and verify system health before starting field work.

Before you start

  • Device is powered on and booted (wait about two minutes).
  • You have the WiFi hotspot password from deployment prep.
  • You are on a phone or laptop with WiFi enabled.

Connect and verify

  1. Join the WiFi hotspot SSID shown on the device label.
  2. Open http://192.168.50.1 in your browser.
  3. Confirm the Simple mode dashboard loads.
  4. Check CPU, memory, temperature, and storage indicators.

Tips

If you need advanced controls, switch to Advanced mode using the mode toggle in the header.
