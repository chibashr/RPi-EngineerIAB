Network management

Configure interfaces, routing, and hotspot behavior from Advanced mode.

Before you start

  • You are connected to the WiFi hotspot.
  • Advanced mode is enabled.
  • You have the site network details (DHCP or static IP).

Configure an interface

  1. Open Advanced → Network.
  2. Select the interface you want to change.
  3. Choose DHCP or Static.
  4. Apply and confirm connectivity.

Adjust routing

  1. Open the Routing tab.
  2. Add a route or update the default gateway.
  3. Confirm WAN connectivity on the dashboard.

WAN priority and failover

After a new connection is applied (e.g. DHCP or static on an interface), the device checks whether the connection is internet-capable. WAN preference is USB network adapter first, then ethernet. If the current WAN interface is lost or has no internet, the rpi-engineer-network service periodically re-evaluates and fails over to the next working interface. You can also trigger a check manually via POST /api/v1/network/wan-priority.
