Remote Console (SSH / Telnet)

Open SSH and Telnet sessions from this device to remote hosts. Use a browser-based terminal (like the Serial console) to connect to routers, switches, or servers.

Before you start

  • You are in Advanced mode and logged in as admin.
  • The remote host is reachable from this device (network path and firewall allow SSH or Telnet).
  • For SSH: paramiko is installed (see requirements.txt).

Open a session

  1. Open Advanced → Remote Console.
  2. Either:
    • New Session → choose a saved target (or use Quick connect with host, port, type, username, password).
    • Click a saved target in the list, then enter password if required and connect.
  3. The terminal opens in a new tab. Type as in a normal SSH or Telnet client.

Saved targets

Use Add Target to save a connection (host, port, SSH or Telnet, optional username and key path). Passwords are not stored; enter them when you connect. You can edit or delete targets from the API if needed.

Security

  • All Remote Console API and sessions require admin login.
  • Only outbound connections are made (this device acts as the client).
  • Restrict targets to trusted hosts and use strong authentication.
