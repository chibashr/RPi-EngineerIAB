Serial console

Open serial sessions, adjust device settings, and download session logs.

Before you start

  • You are connected to the WiFi hotspot.
  • A supported USB-to-serial adapter is connected.
  • Advanced mode is enabled.

Open a session

  1. Open Advanced → Serial console.
  2. Select a detected device.
  3. Confirm baud rate and other settings.
  4. Click Open console.

Manage logs

  1. Keep the session running while you capture output.
  2. Download logs from the session list.

Syntax highlighting

The console supports syntax highlighting for Cisco IOS CLI output. Use the Syntax dropdown to choose:

  • None – Plain text.
  • Cisco – Prompts, commands, errors, and config keywords.
  • Custom – Regex-based rules. Click Configure to add rules as JSON: [{"pattern": "regex", "class": "css-class", "flags": "g"}]. Use CSS classes such as sh-prompt, sh-command, sh-error, sh-config, sh-status.
