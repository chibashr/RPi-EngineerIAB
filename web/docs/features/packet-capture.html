Packet capture

Capture traffic on a selected interface, apply filters, and download results.

Before you start

  • You are connected to the WiFi hotspot.
  • Advanced mode is enabled.
  • You know which interface to monitor.

Start a capture

  1. Open Advanced → Packet capture.
  2. Select an interface.
  3. Optional: enter a BPF filter.
  4. Click Start capture.

Live view and download

  1. Use Live view for real-time packet statistics.
  2. Stop the capture when finished.
  3. Download the PCAP for analysis.
