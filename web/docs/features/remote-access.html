Remote access

Remote access tools provide off-site support when technicians are on location. Supported options include AnyDesk, TeamViewer, VNC, and Raspberry Pi Connect.

Before you start

  • Remote access tool installed during deployment.
  • Device has WAN connectivity (USB or Ethernet).
  • You have the remote access password.

Check status

  1. Open the Simple mode landing page.
  2. Confirm the connection ID is visible.
  3. Verify status is running.

Share connection details

  1. Copy the connection ID.
  2. Share it with authorized support staff only.
  3. Confirm they can connect before leaving the site.
