Remote access

Remote access tools provide off-site support when technicians are on location. Supported options include AnyDesk, TeamViewer, VNC, and Raspberry Pi Connect. TeamViewer is installed per the headless Linux guide (CLI-only, framebuffer when used alone).

Before you start

  • Remote access tool installed during deployment.
  • When you select AnyDesk, the installer configures a virtual display (Xvfb) for headless use. TeamViewer-only installs use the framebuffer console without Xvfb.
  • Device has WAN connectivity (USB or Ethernet).
  • You have the remote access password.

Check status

  1. Open the Simple mode landing page.
  2. Confirm the connection ID is visible.
  3. Verify status is running.

Share connection details

  1. Copy the connection ID.
  2. Share it with authorized support staff only.
  3. Confirm they can connect before leaving the site.

Troubleshooting

  • TeamViewer ID missing on dashboard – See TeamViewer running but connection ID not on dashboard.
  • AnyDesk: "display_server_not_supported" – See AnyDesk: Session closed / display_server_not_supported (usually Wayland; installer configures X11/LightDM for new installs; existing installs run bin/setup-virtual-display.sh then reboot).
